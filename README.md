## 🎯 Vision
Sonification expérimentale des cycles de développement GitHub.

> "Une recherche sur la représentation sonore de l'entropie du code. Commit Sonata transforme la fréquence et la complexité des commits en paysages sonores génératifs via la Web Audio API."
